# علوم‌یار هفتم - کتاب کار ۱۴۰۵

نسخهٔ ۰٫۹٫۰ با شناسهٔ مستقل `com.oloomyar.app.grade7`: هر ۳۱۷ سؤالِ فصل‌های ۱ تا ۱۵، ۳۳۴ بخش تمرینی و ۶۶۸ راهنمای مرحله‌ای آماده است.

صورت سؤال و پاسخ همهٔ فصل‌ها با متن بومی، ۱۵ جدول کامل، ۲۰ بخش فرمولی و شکل مستقل نمایش داده می‌شوند. ۱۱۴ سؤال فصل‌های ۱۰ تا ۱۵ بازبینی و ۸۵ سؤالِ باقی‌مانده تبدیل شدند. گزینه‌ها روشن و قابل انتخاب مجدد هستند؛ جدول‌ها پیمایش افقی ندارند. صفحهٔ هر فصل تصویر ارسالی، پیشرفت واقعی و ادامهٔ تمرین دارد.

۵۲ شکل سؤال و هفت تصویر آموزشی پاسخ از بستهٔ ارسالی متصل‌اند. شکل کامل سؤال ۱۵ فصل ۳ پیش از جای‌خالی‌ها می‌آید. تصاویر حالت درست، نادرست، راهنما، کتاب، نشان و دفتر خالی در رابط استفاده شده‌اند. تصاویر علمی با پیکسل اصلی و WebP بدون اتلاف حفظ می‌شوند.

پس از حل درست یا دو پاسخ کامل نادرستِ متفاوت و هر دو راهنما، درخواست صریح «دیدن پاسخ» همان پاسخ کاملِ کتاب‌کار و تصاویر موجودش را باز می‌کند. یکسان‌بودن این دو مسیر در هفت صفحهٔ واقعی شامل متن، جدول، فرمول و تصویر آزموده شده است. رفتن به سؤال بعدی نیز صریح است. اصل منبع و کلیدهای چاپی حفظ و مغایرت‌های علمی جدا گزارش شده‌اند.
