# علوم‌یار هفتم — کتاب کار ۱۴۰۵

نسخهٔ ۰٫۱۵٫۲، کد نسخهٔ ۱۹، با شناسهٔ مستقل `com.oloomyar.app.grade7` شامل هر ۳۱۷ سؤال فصل‌های ۱ تا ۱۵، متن کامل پاسخ‌ها، ۳۳۴ بخش تمرینی و ۶۶۸ راهنمای مرحله‌ای است.

**ساخت در Android Studio پس از Pull:** کلید عمومی واقعی پرداخت و اثر انگشت آن از `config/bazaar-grade7.properties` خوانده می‌شوند؛ نبودن RSA در `local.properties` طبیعی است و نیازی به تغییر مسیر SDK شخصی نیست. ابتدا APK امضاشدهٔ release را بسازید و تست کنید؛ سپس AAB و BIN را با همان JKS انتشار تولید کنید. [راهنمای کامل Pull تا انتشار](docs/ANDROID_STUDIO_PULL_RELEASE_FA.md). دستور تأیید در PowerShell: `.\gradlew.bat :app:verifyBazaarReleaseConfiguration`.

بخش آزمون، جست‌وجوی سؤال و میان‌برهای ادامهٔ تمرین/یادگیری حذف شده‌اند؛ ورود به تمرین از فهرست سؤال‌ها انجام می‌شود. حرکت تصویر بزرگ‌شده در محیط فارسی، هم‌جهت حرکت انگشت است.

فصل اول رایگان و فصل‌های ۲ تا ۱۵ با یک محصول غیرمصرفی `oloomyar_g7_complete` به قیمت ۱۹۵٬۰۰۰ تومان باز می‌شوند. رسید RSA معتبر پیش از اتصال به بازار از دو نسخهٔ محلی خوانده می‌شود؛ آفلاین‌شدن، اجرای دوباره و بازیابی خالی باعث قفل مجدد نمی‌شوند. نسخهٔ آزمایشی debug برای بازبینی همهٔ فصل‌ها را باز می‌گذارد؛ release قفل واقعی دارد. کلید عمومی **برنامهٔ هفتم** در سورس آماده است؛ برای تست پرداخت، برنامه و محصول باید در بازار ثبت و فعال باشند و نسخهٔ release با امضای انتشار صاحب برنامه ساخته شود؛ [راهنمای تنظیم خرید](docs/BAZAAR_IAP_SETUP_FA.md).

گزینه‌های چهارگزینه‌ای با ترتیب اصلی الف، ب، ج، د نمایش داده می‌شوند. تصویر کامل پنج جدول چاپی کتاب پیش از جدول بومی مربوط می‌آید؛ جدول‌های بومی نیز کامل و بدون پیمایش افقی‌اند. انتخاب‌ها در بانک پاسخ باقی می‌مانند و قابل استفادهٔ مجدد هستند.

پس از بررسی پاسخ کاملاً درست، همان پاسخ کامل متنی و تصویریِ «دیدن پاسخ» خودکار نمایش داده می‌شود و امتیاز حل مستقل حفظ می‌شود. پس از دو پاسخ کامل نادرستِ متفاوت و هر دو راهنما، همین پاسخ با درخواست «دیدن پاسخ» باز می‌شود. رفتن به سؤال بعدی با انتخاب دانش‌آموز است.

هر ۲۶ تصویر درخواستی فصل‌های ۱۱ تا ۱۵ اضافه شد و تصویر اصلاح‌شدهٔ فصل ۷ سؤال ۱۴ جایگزین شد. اکنون ۹۷ تصویر پاسخ و ۵۴ شکل سؤال ارسالی متصل است. متن پاسخ‌ها و بیان سادهٔ مناسب پایهٔ هفتم حفظ شده است. شکل کامل سؤال ۱۵ فصل ۳ همچنان پیش از جاخالی‌های تعاملی می‌آید.

تصاویر تازه بدون کاهش ابعاد، از مجموع ۴۶٫۸۲ به ۱۰٫۰۶ مگابایت فشرده شدند؛ کاهش حجم ۷۸٫۵٪ است. شکل‌های کوچک بدون اتلاف‌اند و کیفیت روشنایی تصاویر بزرگ با حداقل SSIM برابر ۰٫۹۹۵ سنجیده می‌شود. جدول‌های اصلی از همان PDF موجود خوانده می‌شوند و فایل تصویری تکراری به بسته اضافه نمی‌کنند. حجم APK نسخهٔ پیشین ۰٫۱۱ **70.77 مگابایت** بود.

[اجرای موفق نسخهٔ ۰٫۱۱](https://github.com/nranjbar/oloomyar7/actions/runs/39816472053): 43 آزمون واحد، 62 آزمون رابط API 35، ۱۹۰۲ حالت چیدمان، مقایسهٔ دو مسیر پاسخ در ۹۹ سؤال و چهار آزمون نصب ارتقایی/بازیابی فرایند موفق شدند. هر ۱۵۱ تصویر علمی روی اندروید رمزگشایی و با پیکسل‌های مرجع نهایی تطبیق داده شد. تمام ۲۴۳ فایل داخل APK با منابع ثبت‌شده برابرند. امضای APK آزمایشی ثابت است؛ AAB انتشار به کلید تولید نیاز دارد.
