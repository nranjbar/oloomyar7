# علوم‌یار هفتم — کتاب کار ۱۴۰۵

نسخهٔ ۰٫۸٫۰، شناسهٔ مستقل `com.oloomyar.app.grade7`: ۳۱۷ سؤال، ۳۳۴ بخش تمرینی و ۶۶۸ راهنمای مرحله‌ای از هر ۱۵ فصل.

صورت سؤال و پاسخ هر ۲۳۲ سؤال فصل‌های ۱ تا ۱۰ با متن بومی، جدول کامل، فرمول و شکل مستقل نمایش داده می‌شود. گزینه‌های مبهم تمرین روشن‌تر شده‌اند و فهرست‌های انتخابی، از جمله صحیح/غلط، امکان انتخاب مجدد هر گزینه را دارند. جدول‌ها پیمایش افقی ندارند و صفحهٔ هر فصل تصویر ارسالی، پیشرفت واقعی و ادامهٔ تمرین دارد.

۴۰ شکل سؤال و هفت تصویر آموزشی پاسخ از بستهٔ ارسالی متصل‌اند. شکل کامل سؤال ۱۵ فصل ۳ پیش از جای‌خالی‌ها می‌آید. تصاویر حالت درست، نادرست، راهنما، کتاب، نشان و دفتر خالی در رابط استفاده شده‌اند. تصاویر علمی با پیکسل اصلی و WebP بدون اتلاف نگهداری می‌شوند.

پاسخ مرجع و تصویر آموزشی آن فقط پس از حل درست یا دو پاسخ کامل نادرست متفاوت و نمایش هر دو راهنما، با درخواست صریح دانش‌آموز باز می‌شوند. رفتن به سؤال بعدی نیز صریح است. اصل متن سؤال‌ها، پاسخنامه‌ها و PDFهای ۱۴۰۵ حفظ شده و تفاوت معیار علمی تمرین با کلید چاپی یادداشت جدا دارد.
