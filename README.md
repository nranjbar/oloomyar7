# علوم‌یار هفتم — فصل‌های ۱ و ۲

اپ مستقل اندروید علوم پایه هفتم، بر اساس کتاب کار علوم هفتم ۱۴۰۵ و پاسخنامه‌های داخل `haftom.zip`.

| فصل | سؤال اصلی | چهارگزینه‌ای | مرحله تعاملی |
|---|---:|---:|---:|
| ۱: تجربه و تفکر | ۸ | ۰ | ۱۱ |
| ۲: اندازه‌گیری در علوم و ابزارهای آن | ۱۵ | ۵ | ۳۰ |
| مجموع | ۲۳ | ۵ | ۴۱ |

صورت اصلی کتاب اول نمایش داده می‌شود، سپس تصویر و پاسخ تعاملی. رابط و رفتار تمرین‌ها همان طراحی نسخه نهم است: تمرین، دو راهنما، نمایش پاسخ، آزمون، مرور اشتباهات، ذخیره پیشرفت و بزرگ‌نمایی شکل. تمام کد و محتوای لازم در همین مخزن است.

## ساخت

با JDK 17 و Android SDK 37:

```bash
./gradlew :app:assembleDebug
```

ویندوز: `gradlew.bat :app:assembleDebug`. خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

شناسه نصب: `com.oloomyar.app.grade7`، نام: «علوم‌یار هفتم». بدون تنظیم اضافه همین اپ هفتم ساخته می‌شود و می‌تواند کنار اپ نهم نصب شود. هر دو فصل نسخه بازبینی باز هستند.

## بازبینی سؤال و تصویر

- متن و مراحل: `app/src/main/assets/content/chapter1.json` و `chapter2.json`.
- ۱۱ تصویر مورد استفاده: `app/src/main/assets/images/`.
- بسته بازبینی: `review/index.html`، تصاویر PNG، تصاویر اصلی PDF، صفحه‌های منبع و هفت پیشنهاد تصویر پاسخ.
- جزئیات محتوا و ابهام‌های منبع: [docs/GRADE7_CHAPTERS1_2_FA.md](docs/GRADE7_CHAPTERS1_2_FA.md).

تصویر سؤال ۹ فصل ۲ با عددهای متن سازگار نیست و باید جایگزین شود: جرم ۳۶ گرم، حجم اولیه ۶۰ و نهایی ۷۲ سانتی‌متر مکعب. فعلاً محاسبه بر اساس متن انجام می‌شود. تصاویر بهتر با همان نام فایل جایگزین شوند.

## بررسی

```bash
python3 scripts/validate_grade7.py
./gradlew :app:testDebugUnitTest :app:connectedDebugAndroidTest
```

workflow `Grade 7 Review` پوشش محتوا، ساخت APK، آزمون واحد و چهار آزمون واقعی رابط فارسی را بررسی می‌کند و فایل نصب، گزارش‌ها و اسکرین‌شات‌ها را ارائه می‌دهد.
